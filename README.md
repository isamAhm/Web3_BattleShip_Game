# Web3 BattleShip Game

A multiplayer Battleship game built for the Web3 Battle Arena hackathon.

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Installation

Clone the repository and enter the project directory:

```bash
git clone https://github.com/isamAhm/Web3_BattleShip_Game.git
cd Web3_BattleShip_Game
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Development

This project uses [Next.js](https://nextjs.org) and was bootstrapped with `create-next-app`.

- Edit `app/page.tsx` to modify the main page.
- Changes are reflected automatically during development.
- Run `npm run build` to build the application for production.
